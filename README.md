# Don't stop running — тестовая версия

Мрачный раннер для телефона: Флит Вейн бежит через 400 комнат поместья «Паноптикум».

**Играть:** https://chetyrko.github.io/dont-stop-running/

Открывай на телефоне в обычном браузере, держи вертикально. Регистрация не нужна. Прогресс сохраняется в этом браузере.

## Управление

| Жест | Действие |
|---|---|
| свайп ↑ | прыжок: ямы, руки из пола, низкие вороны, обломки люстр |
| свайп ↓ | подкат под вороной |
| свайп ← | пинок шкафа |
| свайп → | рывок сквозь призрачную решётку |
| тап | выстрел в тень |
| тап по глазу сверху | пауза |

## Нашёл баг?

Напиши автору: что делал, в какой комнате, на каком телефоне и какая сложность стояла. Скриншот очень помогает.

Здесь лежит только собранная игра. Её автоматически выкладывают сюда из основного проекта.
